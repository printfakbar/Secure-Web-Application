# Secure Web Application

## Project Overview

This project is a Secure Web Application developed using Flask and SQLite. It demonstrates secure user authentication, password hashing, session management, and protected routes.

## Features

- User Registration
- User Login
- Password Hashing (SHA-256)
- Session Management
- Dashboard
- User Profile
- Change Password
- Logout
- SQLite Database

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Installation

```bash
pip install flask
```

Run the application:

```bash
py database.py
py app.py
```

Open:

```
http://127.0.0.1:5000
```
